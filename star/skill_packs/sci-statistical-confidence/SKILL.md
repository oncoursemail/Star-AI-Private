# sci-statistical-confidence
## Scope
Use when reporting that one arm scored higher than another. Guidance on stating confidence; it computes nothing by itself.

## Steps
1. Report counts (passes out of tasks), not only percentages.
2. Compare arms on the same tasks and look at paired differences: tasks gained, tasks lost.
3. Give an interval (for example a bootstrap or Wilson interval) for the difference, and say how it was computed.
4. If the interval includes zero, say the result is inconclusive, not neutral.
5. Fix the number of comparisons beforehand; many looks at the same data inflate false wins.
6. Rerun flipping tasks. A gain on a handful of tasks is a lead to test, not a finding.

## Fallback
With too few tasks for an interval, report the raw counts and say confidence cannot be stated.
