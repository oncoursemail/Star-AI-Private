# Anti-slop UI (anti-slop-ui v3.2.21, MIT)
- Pick one accent colour with a stated role and neutral surfaces; no more than a few colours, no default blue-purple gradient, no glow or blur on every component, no background grid or blobs without a purpose.
- Vary radius, shadow and spacing by role (inputs, cards, buttons, modals are not all the same pill with the same soft shadow). Vary section composition; avoid the hero, three cards, testimonials, FAQ template.
- Icons: one coherent set sized to the text, not sparkle/lightning/robot stand-ins; no arrows on every button, no coloured left stripe on every card, no eyebrow capsule above the headline.
- Type: choose a typeface for a reason, with a real scale and weights; no large monospace headings or wide-tracked uppercase labels as decoration.
- Motion only to explain a change (state, entry, feedback); no template fade-up on everything; respect prefers-reduced-motion.
- Apps and dashboards: real data shapes, empty/loading/error states, a clear primary action, tables and filters that work; no skeleton blocks passed off as a product shot.
