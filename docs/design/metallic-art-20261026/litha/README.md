Every PNG has genuine alpha transparency. The six chibis have alpha range 0–255; the full-body output has range 0–254. Exact 1024px chibi exports remain outstanding: the tool returned larger masters despite the requested canvas. These originals were preserved without raster post-processing.

All seven were visually reviewed with no obvious extra limbs or hard clipping. Some fine coloured fringes and faint alpha noise remain around hair/glow contours. These need a light/dark launcher-background check and export cleanup before production approval. This set does not install a mascot or supply animation states. Crow branding, layered wallpapers and game tiles remain separate unfinished requests.
