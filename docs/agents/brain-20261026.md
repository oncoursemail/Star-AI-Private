## Wiring (outside star/inner, small)
- `star/home/__main__.py`: `life = wrap_life(Life(home), home)`. `MindLife.pick` asks the planner (None = rest; the loop
  then idles), `record` adds episodic + procedural memories (outcome = `verified`, never the model's claim; compatible
  with #644's verified-only rule), spends energy, nudges the interest x1.03 / x0.97 by mood. Everything else delegates.
- `star/home/brain.py` `run_session`: `life.session_context(interest, goal)` appended to the session user message
  (summary + up to 3 relevant lessons/insights/attempts; no person-linked memory). Two lines; #644 also edits this
  function (its `life_recall_enabled` block): expect a small textual merge.
- `star/inner/night.tick` (already called by the home loop every cycle) now also calls `Mind.tick`, and on her PC with
  `model_calls` swaps the loop's plain `complete` for `structured.schema_complete(config)`, so night calls are
  grammar-constrained. No change to `star/home/loop.py`.
- `star/social/chat.py`: after a reply `_mind_observe` (one inbox line, no model), on "forget me" `_mind_forget` before
  friend memory deletes the row. Content only from confirmed adults outside Roblox; possible minors / unknown age /
  Roblox give "Chatted with X on P" only.
- Not wired on purpose: the summary into the social chat system prompt. The inner chat hook was measured (#669: 16/16,
  p = 1.0) and stays OFF; the earlier generic self block lost 10 vs 21. Wire it behind `inner_chat_enabled` once a blind
  A/B shows a win.

## Owner commands
`python -m star.inner brain | page | plan | memories [query] | facts | settings | set NAME VALUE | forget-person KEY | stop`.
Stop = the existing STOP file (also `python -m star.home stop`, desktop button, Ctrl+Alt+Shift+F12); the mind does nothing
while it exists. Actions go to star-home's `actions.jsonl` as action `inner` (plan, choose, night, forget, error).

## Research applied (lead's message, docs/research/companion-life-20261026.md)
1. Constrained decoding for every structured output: `structured.py`, all inner calls; tolerant parse + one retry behind it.
2. Zep/Graphiti temporal facts: `valid_from` / `invalid_at` / `superseded_by` in `stream.py`.
3. Write memory at night / in the background, not in the chat path: inbox append only on hot paths.
4. LongMemEval-style test: `memeval.py`.

  vectors (verify on her PC: `python -m star.inner memories obby` after a day).
- Grow memeval toward the research doc's 100-200 synthetic histories and run it with the remote embedder.
- Rule fact patterns cover favourite X / work / learning / pet name; the constrained brain extraction covers the rest
  at night (untested live).
- Emotion events are ingested only when `emotion_enabled` is on (default OFF until its A/B wins), so memories carry a
  neutral mood until then.
