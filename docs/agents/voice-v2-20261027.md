# voice-v2-20261027: Star's voice rebuilt around what the owner rated well

Branch `star/voice-v2-20261027`, stacked on `star/voice-expressive-20261026` (PR #697). Board item #280, owner Claude.

Why: the owner rated round 1 "mostly bad" (`work/voice-expressive/samples/ratings.jsonl`). Only the Qwen3-TTS
VoiceDesign characters scored OK (Professor Wren 2-4, The Dragon 3-4). Every Kokoro style, every Kokoro+DSP effect, the
Qwen3 clone styles, ASMR, both songs and the Chatterbox laugh/sigh/gasp/cough scored 1-2.

## What changed in code (tested: `tests/test_voice_expressive.py`, 40 passed; 45 voice/senses test files 804 passed,
1 timing flake in test_voice_acks that passes alone and on the base branch)
- **DSP styles removed** (`star/voice/expressive.py`): no WORLD pitch shaping, no spectral whisper, no ASMR shelf or
  compressor, no ASMR breath clips, no style speed change. The live Kokoro path speaks plainly; tone comes only from an
  engine that makes it itself. `voicedsp` stays for loudness, fades and room tone.
- **Emotion from the model**: `ExpressiveTTS._neural` passes the style's instruction only to engines with
  `follows_instruct = True`. New engine `qwen3-design` = `StarDesignTTS` (`star/voice_neural.py`): Star's designed
  voice (description + seed; in VoiceDesign the seed is part of the voice) plus the style's instruction. It streams.
  `QwenCloneTTS` (`qwen3-tts`) is marked as not following instructions (the Base model ignores them) and now clones her
  designed voice when `<home>/reference/star-<key>.wav` + `.txt` exist (`designed_reference`), else her Kokoro voice.
- **Star's voices**: `STAR_VOICES` (8 candidates) and `DEFAULT_STAR_VOICE = "j-girlfriend"` (provisional, the most
  stable adult pitch; the owner's rating picks). New setting `star_voice` (validated). `EXPRESSIVE_ENGINES` is now
  `kokoro | qwen3-tts | qwen3-design`; `chatterbox-turbo` removed; VRAM gate `qwen3-design` 4.7 GB.
- **Non-verbals**: `nonverbal.NATIVE_ENGINES` is empty (Chatterbox rated 1-2), the bank is no longer loaded by
  `build()`, and laugh/giggle/chuckle no longer fall back to reading "Ha ha!": a sound with no native engine is skipped.
  Fillers (um, mm-hm) stay as words.
- **Singing paused** (`singing.SINGING_PAUSED`): `can_sing` always declines with an offer to write the words; `<sing>`
  lines are spoken in the reply's tone; the persona prompt tells her not to sing for now.
- **Kept**: artefact guard (every v2 sample went through it: ASR round trip, signal checks, speaker similarity where a
  reference exists), the streaming path (Qwen clone + design `stream()`), the real-time Kokoro path.
- Lab: v1 `samples` no longer renders songs. The v2 round is `tools/voice_v2/` (work folder via `STAR_VOICE_V2_WORK`,
  default `<repo>/../../work/voice-v2`).

## The A/B round (`work/voice-v2/samples/`, 62 WAV + MP3; metadata in `docs/design/assets/voice-v2-20261027/`)

   None of the "whispers" is a real whisper (voiced share 0.39-0.48 vs 0.5-0.6 for normal speech; v1's DSP whisper
   was 0.0 but sounded artificial). The owner's ears decide which tones are convincing.
3. **Non-verbals**: CosyVoice 3 inline tags `[laughter]`, `<laughter>...</laughter>`, `[sigh]`, `[breath]`, `[cough]`
   (5 samples). The recogniser heard no "ha ha" or tag words, so the tags are rendered as sounds, not read out; one
   sample (sigh) had a loudness jump. Qwen3 and IndexTTS have no inline tags. If the owner rates these low, sounds stay
   off (the code already skips any sound without a native engine).
4. **Singing**: not rendered. No engine tested sings; paused in code.

Not tested: **Higgs Audio v2** (Boson community licence, commercial OK under 100k annual active users, attribution;
11.6 GB bf16: does not fit the 8 GB card or the disk). **F5-TTS**: weights CC-BY-NC-4.0 (not commercial), skipped.
**IndexTTS-2**: IndexTTS-2.5 (same family and licence, Aug 2026, smaller) was tested instead.
