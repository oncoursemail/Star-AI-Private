# game-play-20261026: notes (resume file)

Branch `star/game-play-20261026`, worktree `worktrees/game-play`, board item #255. Research, design and limits are
in `docs/research/game-play-20261026.md`.

## Built
- `star/play/humanlike.py`: ex-Gaussian reaction times, Fitts-law pointing time, curved minimum-jerk paths with
  overshoot and correction, misses, hold jitter. `Actuator` plays timed events on its own thread; a newer aim
  replaces a pending one, and a held key is extended rather than pressed again.
- `star/play/winput.py`: SendInput with scan codes. Every event checks first that the game window is in front.
- `star/play/capture.py`: BitBlt into a numpy-mapped DIB section (ctypes, no new packages); dxcam and mss are
  used when installed; `FakeFrames` for tests.
- `star/play/percept.py` and `perception.py`: `ColorDetector` (numpy grid blobs), `YoloDetector` (YOLOv8/11 ONNX
  decode + NMS), `ChatOCR` (RapidOCR-style rows, keeps only new lines).
- `star/play/planner.py`: `LLMPlanner` (any streaming `Brain`, 2.5 s deadline, accepts only goals from the game's
  list, wraps chat as data).
- `star/play/loop.py`: `FastLoop`, `SlowLoop` (woken by game moments, speech rate-limited), `GameSession`,
  `LatencyStats`; listeners for the voice `GameMomentWindow` and star.emotion.
- `star/play/roblox.py`: `ObbyController` and `ScreenObserver`.
- `star/play/minecraft/`: `skills.py` (library, static check, `check_expect`, `MinecraftLink`, `SkillRunner`, 4
  unverified seeds), `learner.py` (Voyager loop), `reflex.py` (10 Hz reflexes with reaction delay),
  `skill_runner.js` (Node: vm skill runner, human-speed `h.look`, 10 Hz state stream).
- `star/play/session.py`: `roblox_obby_session(...)` and `minecraft_session(transport, ...)`.
- `star/play/bench.py`: `python -m star.play.bench [--real-capture] [--concurrency S] [--size WxH]`.

## Numbers (owner's dev PC, RTX 3060 Ti; Python 3.12; below-normal priority, pc_guard idle class)
- Fake 1280x720 obby frame, one fast tick: detect p50 4.8-6.5 / p95 5.7-9.3 ms over runs; decide 0.02 ms; act
  (human plan) 0.03 ms; capture-to-action p50 4.8-6.6 ms. 1080p: detect was 15-20 ms with stride fixed at 4; with
  the stride following the resolution (~320 samples across) it is p50 5.7 / p95 9.1 ms.
- Real screen BitBlt: 720p grab p50 25-27 ms (17 ms in a standalone try), 1080p 35 ms. Pillow ImageGrab: 60 ms
  (720p) and 66 ms (1080p). Grab plus detect at 720p: p50 33 ms, p95 38-39 ms, so 20 Hz fits.
- Concurrency: fast loop at 20 Hz with a fake planner taking 0.8 s per call: tick interval p50 50.0 / p95 50.5 ms
  (max 86), 1 overrun in 99 ticks, 5 planner calls, 5 lines spoken.
- Human delays (generator): reaction p50 247 / p95 387 ms; aim 100 px/W40 297 ms, 400 px/W40 495 ms,
  800 px/W20 723 ms.
- Windows `time.monotonic` ticks every 15.6 ms. The loop uses `perf_counter` (moments sent to the voice window are
  stamped with `monotonic`, which is that window's clock).
