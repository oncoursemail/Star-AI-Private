## Pipeline (star/asset3d)
brief -> litha writes a part spec (attach layout: parts name a parent face + u/v; code computes coordinates, so parts
touch by construction) -> spec.prepare (validate, resolve layout, arrays, mirrors, ground) -> build_bpy.py in Blender:
parts (box/taper, cylinder, cone, sphere, torus, profile extrude, lathe, tube) + boolean cuts + seam panel lines +
bevel (harden normals) -> procedural materials per style (PBR: edge wear via Bevel-node mask, grunge, wood grain;
stylized: height gradient + edge highlight + AO cavity + mottling; lowpoly: flat facets) -> one game mesh, smart UV +
pack -> Cycles bakes (colour, normal, roughness, metallic, AO, emission mask; AO multiplied into colour) -> QA
(tris, non-manifold, zero-area, UV overlap raster, texel density p90/p10, contact graph / floating parts, size) ->
studio renders (3-point area lights, cyclorama, 4 views) -> star-fast critique vs rubric -> litha patch -> rebuild
(keep best by critic score minus QA penalty) -> final build: LOD0/1/2 (decimate 0.5/0.25), GLB + FBX + OBJ, maps.
