## Decision (step 2), with evidence
- **star-fast adapters (Qwen3.6-35B-A3B): not trainable on this PC.** The served file is 20.4 GB at Q4_K_M; a QLoRA
  base in NF4 is ~18-19 GB before activations, against 8 GB VRAM and ~14 GB free system RAM (32 GB total, owner apps
  open); the bf16 weights to train from are ~70 GB (80 GB free on C:). Even with CPU offload it would not fit in
  free RAM, and step time would be minutes. Not attempted.
- **4B apprentice LoRA (Qwen3-4B-Instruct-2507): trainable** (SFT 2 epochs ~33 min, 7.3 GB peak; KTO below).
  It can only improve live answers if it beats what is live: star-fast's v1.0.0 numbers on the same suites are
  v2 16/34, creation 10/23 (median 183 s / 394 s per answer, work/eval-runs/v100-*.json).
- **Exemplar bank (control):** the app's own worked-example retrieval with the same decontaminated rows.
- So the gate compares, through STAR's real answer pipeline with the 4B on the PC GPU: base, bank (control), SFT, KTO.
