# home-gaps (2026-10-26): adult persona text, three emotion sources, watch hearing hub

Branch `star/home-gaps-20261026` (from star/next 0b171017). Closes three gaps of docs/HANDOFF-CODEX-20261026.md section 4.5.

1. Adult persona path. `star/social/chat.py` `_ROMANCE["allowed"]` now says she may flirt and show romantic affection (also in
   role-play, following their lead); `ask_age` and `friends_only` are unchanged. The system text is chosen only by
   `rules.romance_mode`, so it stays byte-identical per (platform, romance mode). `star/inner/self_model.py`: `render(model,
   romance=False)` and `persona_for_day(store, now, romance=False)` leave out every flirting/romance clause (also ones she wrote
   into identity, humour, quirks ...) and add `FRIENDS_ONLY_LINE` unless `romance=True`; the cache key has a `:romance` suffix.
   `persona_for_day` still has no caller (the social chat does not use the daily persona yet): a caller must pass
   `romance=(mode.romance == "allowed")`.
2. Emotion events. `reunion`: `SocialChat._reunion` (a friend silent for >= 3 days, `FriendMemory.silent_for`), strength 0.5-1.0.
   `friend_left`: a casual goodbye (`chat.GOODBYE`) from a friend in chat (`SocialChat._feel`) or in a call
   (`DiscordCalls._watch_goodbye` reads the voice session history), strength 0.35, once per call. `left_out`:
   `attention.LeftOutWatch` (>= 6 unaddressed messages from >= 2 people, 1 h cooldown) fed by `DiscordDesktop.step` for server
   channels; only when a friend is among the speakers (`FriendMemory.known` never creates a record for strangers).
   Not covered: left_out inside a call (the voice session has no per-speaker data) and a friend leaving a call without saying
   goodbye (no signal without a screen read per tick).
3. Watch hearing hub. `plugins.hearing_hub(rt)` -> `watch.configure(hub=...)` when a video starts; `voicestack.hearing_hub` calls
   `senses.instant.start_hearing` (lazy, retried every 5 min after a failure, None -> captions/picture). Her speakers are wrapped
   in `ReferenceSpeaker` with the shared reference so her own voice is not heard. The voicestack part is not run (needs her PC).
