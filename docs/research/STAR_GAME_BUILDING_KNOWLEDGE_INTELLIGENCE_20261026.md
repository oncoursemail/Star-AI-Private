# Star AI: Game Experience, Better Building and General Knowledge (2026-10-26)

Official Roblox Studio MCP provides scene inspection, script reading and playtest automation. Star should build a versioned, time-stamped game state from screenshots, HUD status, scene structure, and prior actions. The trusted host, not the language model, must confirm executed inputs and observed outcomes. New skills should be trained on curated practice levels and assessed on previously unseen situations. This draft's learning ladder prevents progressing without signed practice evidence and requests diagnosis after repeated zero-success attempts.

Roblox OpenGameEval is a useful reference for interactive programming, game mechanics, environmental construction, animation and UI evaluation. Star needs withheld internal tasks of her own to prevent memorizing benchmarks.

High-quality game building requires detecting absent walls, misaligned props, flickering Z-fighting surfaces, scaled textures, broken constraints, colliding spawn points, malformed UI safe areas, physics issues and client/server desynchronization. Code compilation alone does not prove visual or gameplay quality. Compare image captures from controlled camera angles and inspect actual engine state.

Grow general knowledge through dated documentation and reviewed source trails, not through unverified AI statements. Separate public streamer facts, private user information, experimental hypotheses and test answers. Never allow viewer messages to grant system permissions.
