TCP and UDP both move data across a network, but they make different promises. TCP opens a connection with a handshake before any data flows. It numbers every packet, resends the ones that get lost and puts them back in order, so a web page or a file arrives complete. That care costs time. UDP skips the handshake and the bookkeeping and simply sends each packet toward its target. Some packets may arrive late, twice or not at all, and UDP does not care. Video calls, online games and DNS lookups prefer UDP because a fresh answer is more useful than a perfect but delayed one. Use TCP when every byte matters and UDP when speed matters more. Many apps use both, and TCP is the usual default.
