How updates stay safe

Signed, checked, and reversible.

Each channel is a file we sign with a key that never leaves our own PC. The launcher knows the matching public key, refuses anything it cannot verify, downloads only the files that changed, checks every file against its hash, and installs the new version beside the old one. If the new version fails to start, the launcher switches back by itself.

You can check a first-install download yourself. On Windows, run certutil -hashfile <file> SHA256 in a terminal and compare the result with the checksum shown above.
