Which chip
Apple menu, About This Mac
  1. Install it. Open the .dmg and drag Metallic to Applications. Start it from there, not from the .dmg.
  2. Allow the first start. Metallic is not signed by Apple, so macOS stops it. Open System Settings, Privacy & Security, scroll down and click Open Anyway.
  3. Revivals are Windows games, and none has been seen running on a Mac yet. Turn on Experimental in Storage and Metallic tries them through Wine. Expect failures, and there is no VR.
  • Live counts, news and links need no Wine.
  • Sound needs macOS 15.4 or newer.
